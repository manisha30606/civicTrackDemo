# CivicTrack recruiter demo

This static walkthrough uses fictional data. Visitors can switch between Citizen,
Admin, Field Worker, and Following. The workflow runs in the browser and resets
when the page reloads.

## Run locally

Extract the ZIP and open index.html in your browser.

## Deploy

Upload the extracted folder containing index.html to Netlify Drop
(https://app.netlify.com/drop). No build command or environment variables are needed.
For another static host, publish the directory containing index.html.

Open the resulting HTTPS URL in an incognito window and check the report,
assignment, resolution, closure, following, and reset controls. Use the URL as
the Interactive Demo link on your resume.

The full CivicTrack application is deployed separately from this walkthrough.
